<h2><a href=https://www.codewars.com/kata/6a6c7d7231db37e1dfe82ef2/train/python target="_blank">Place for an introvert</a></h2><h3>7 kyu</h3><h1 id="place-for-an-introvert">Place for an Introvert</h1><h2 id="scenario">Scenario</h2><p>Imagine you are an extreme introvert. You need to find a place to sit in a public area (like a bus, cinema, or lecture hall). The most important condition for your psychological comfort is choose a suitable location with no active or potential neighbors on either side.</p><p>But introverts are clever: they think one step ahead. You need to write an algorithm that chooses a seat that minimizes the number of current neighbors <strong>and</strong> limits the chance of someone sitting right next to you in the future.</p><h2 id="tactical-seating-rules">Tactical Seating Rules</h2><p>The input is a string <code>seats</code> consisting of the following characters:</p><ul><li><code>0</code> — an empty seat;</li><li><code>1</code> — an occupied seat;</li><li><code> </code> (space) — an aisle, gap, or wall (a safe zone; people across a space do not disturb you).</li></ul><p>Each empty seat (<code>0</code>) is evaluated by the number of <strong>threats</strong> to its left and right sides. A side is considered a <strong>threat</strong> if it contains:</p><ol><li>An occupied seat (<code>1</code>) — a current neighbor.</li><li>An empty seat (<code>0</code>) — a potential future neighbor who might sit there later.</li></ol><p>The boundaries of the string and spaces (<code> </code>) are <strong>not threats</strong> (nobody can sit there). </p><blockquote><p><strong>Critical Rule:</strong> An introvert will <strong>never</strong> accept a seat with 2 threats (trapped between current or potential neighbors on both sides). If a seat has 2 threats, it is considered completely unacceptable.</p></blockquote><p>The introvert always chooses the seat with the <strong>minimum total number of threats</strong>, as long as it has <strong>fewer than 2 threats</strong>.</p><blockquote><p><strong>Note:</strong> If multiple valid seats have the exact same minimum number of threats (0 or 1), the introvert will always choose the first available option from left to right.</p></blockquote><h2 id="output">Output</h2><ul><li>The function should return a string representing the seating arrangement, with the chosen ideal empty seat marked as occupied (<code>1</code>).</li><li>If there are no empty seats (<code>0</code>) available, or if all available seats are unacceptable (have 2 threats), the function must return <code>None</code> / <code>nil</code>.</li></ul><h2 id="examples">Examples</h2><ul><li><code>"1000100"</code> -&gt; <code>"1000101"</code> </li><li><code>"000"</code> -&gt; <code>"100"</code> </li><li><code>"000 01"</code> -&gt; <code>"100 01"</code> </li><li><code>"101"</code> -&gt; <code>None</code> / <code>nil</code></li><li><code>"10101"</code> -&gt; <code>None</code> / <code>nil</code></li></ul>
