<h2><a href=https://www.codewars.com/kata/69269262ced9e95dc63abd1e/train/python target="_blank">The Jumbler</a></h2><h3>7 kyu</h3><br><h1 id="situation">Situation</h1><p>One day Alice was at the casino on her favorite slot machine ("The Jumbler") when she noticed a set of numbers occasionally flashing in one corner of the screen. She found that by treating them as indices, reordering them according to a pattern, and counting the reorderings, she could know how many spins to make before the machine would finally hit a big jackpot payout!<br><br></p><h1 id="reordering">Reordering</h1><p>The pattern Alice discovers goes as follows:</p><ul><li>select the value at index <code>zero</code></li><li>(if the value is <code>0</code> do not continue)</li><li>elsewise, the value is our search index</li><li>go to new value found at the search index</li><li>remove this new value from its place in order</li><li>reposition this new value onto the front of the list</li><li>(if the new value is <code>zero</code>, the reorderings will cease)</li><li>elsewise, repeat all instructions with this new ordering<br><br></li></ul><h1 id="task">Task</h1><p>Write a function to help Alice find out the count<br>of times the given integers have to be reordered<br>and thus know how many Jumbler spins to make<br>before betting large and getting a huge payout!!<br><br></p><h1 id="input">Input</h1><p>A(n) <code>array / list / tuple / vector</code> of unsigned integers.</p><ul><li>values represent the indices of the collection itself</li><li>thus the values are all distinct from one another </li><li>and all indices guaranteed to be present</li><li>the values will be randomly shuffled<br><br></li></ul><h1 id="output">Output</h1><p>An unsigned integer&nbsp;&nbsp;&nbsp;&nbsp;<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;of the count of times the given numbers must be reordered<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;according to Alice's Reordering Pattern<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;before the value at index <code>zero</code> actually becomes <code>0</code> itself.<br><br></p><h1 id="example">Example</h1><h3 id="step-1">&nbsp;&nbsp;&nbsp;&nbsp;Step 1</h3><p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Given the numbers <code>2, 0, 3, 1</code>, we select <code>2</code> as the search index.<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;The value <code>3</code> is found at that index, so <code>3</code> is moved to the front.</p><h3 id="step-2">&nbsp;&nbsp;&nbsp;&nbsp;Step 2</h3><p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Now with numbers <code>3, 2, 0, 1</code>, we select <code>3</code> as the search index.<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;The value <code>1</code> is found at that index, so <code>1</code> is moved to the front.</p><h3 id="step-3">&nbsp;&nbsp;&nbsp;&nbsp;Step 3</h3><p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Now with numbers <code>1, 3, 2, 0</code>, we select <code>1</code> as the search index.<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;The value <code>3</code> is found at that index, so <code>3</code> is moved to the front.</p><h3 id="step-4">&nbsp;&nbsp;&nbsp;&nbsp;Step 4</h3><p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Now with numbers <code>3, 1, 2, 0</code>, we select <code>3</code> as the search index.<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;The value <code>0</code> is found at that index, so <code>0</code> is moved to the front.</p><h3 id="conclusion">&nbsp;&nbsp;&nbsp;&nbsp;Conclusion</h3><p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;With <code>zero</code> now finally at the front of the order: <code>0, 3, 1, 2</code><br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;the reordering comes to a close, and we have our answer.</p><p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;In this case, it took <code>4</code> steps of reordering to jumble zero to the front.<br><br></p><h1 id="enjoy">Enjoy!</h1><p>&nbsp;&nbsp;&nbsp;&nbsp;...and please consider one of the following kata to solve
