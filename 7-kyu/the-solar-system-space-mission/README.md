<h2><a href=https://www.codewars.com/kata/6aa8e25b5ae7dfbbe29e8fb8/train/python target="_blank">The Solar System - Space Mission</a></h2><h3>7 kyu</h3><h2 id="task">TASK</h2><p>Your job is to verify whether a space mission would be successful or not!</p><p>Given a list containing the entire solar system, the destination planet and the megalitres of fuel in the tank, you have to return a boolean that says whether the mission would be successful or not.</p><p>Note that you always launch the spaceship from <code>"Earth"</code>.</p><p>The only items that will be in the list are:</p><ul>  <li><strong>Planets</strong>. Any of <code>["Earth", "Mercury", "Venus", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune"]</code>. There will never be more than one of each. There will always be an <code>"Earth"</code> in the list and there will also always be one destination planet in the list. So the list will never be empty and will always have one <code>"Earth"</code> and one other planet at a minimum.</li>    <li><strong>Asteroids</strong>. Zero or more number of asteroids can be present in the Solar System list, though they will never be the destination. Asteroids will also be title cased, like <code>"Asteroid"</code>.</li></ul><p>The spaceship would go around all the other objects in the solar system towards the <code>destination_planet</code>. A dictionary is given preloaded under the name <code>fuel_map</code> that has the fuel required in megalitres to go around each planet. It looks like this.</p><pre><code class="language-python">{  <span class="cm-string">"Asteroid"</span>: <span class="cm-number">1</span>,  <span class="cm-string">"Mercury"</span>: <span class="cm-number">2</span>,  <span class="cm-string">"Venus"</span>: <span class="cm-number">4</span>,  <span class="cm-string">"Mars"</span>: <span class="cm-number">3</span>,  <span class="cm-string">"Jupiter"</span>: <span class="cm-number">12</span>,  <span class="cm-string">"Saturn"</span>: <span class="cm-number">11</span>,  <span class="cm-string">"Uranus"</span>: <span class="cm-number">8</span>,  <span class="cm-string">"Neptune"</span>: <span class="cm-number">7</span>}</code></pre><p><em>Note: there is no <code>"Earth"</code> in this map as the spaceship should never have to go around <code>"Earth"</code>, as it starts from there and there is always only one <code>"Earth"</code></em></p><p>Finally, to land, the spaceship needs twice as much fuel required to go around the specific planet, so a spaceship would require <code>2 * 12</code>, (<code>12</code> being the amount of fuel required to around <code>"Jupiter"</code>), which is <code>24</code> megalitres of fuel to land on <code>"Jupiter"</code>.</p><p>Given the megalitres of fuel the spaceship has in it as an integer, you have to return <code>True</code> if the spaceship travels from <code>"Earth"</code> to the <code>destination_planet</code> and lands on it without running out of fuel. If it doesn't, you return <code>False</code>.</p><h2 id="example">EXAMPLE</h2><p>Given the <code>solar system</code> = <code>["Mercury", "Asteroid", "Earth", "Asteroid", "Saturn", "Venus", "Neptune", "Asteroid"]</code>, <code>destination_planet</code> = <code>"Neptune"</code> and <code>fuel</code> = <code>33</code>, this is what the spaceship would do:</p><hr><p>The spaceship launches from <code>"Earth"</code> towards the right, where <code>"Neptune"</code> is. First the spaceship crosses a <code>"Asteroid"</code>, which has a fuel use of <code>1</code> to go around in the preloaded <code>fuel_map</code>. So the amount of fuel becomes <code>32</code>.</p><p><em><strong>Fuel left: 32</strong></em></p><hr><p>Then it crosses <code>"Saturn"</code>, losing <code>11</code> megalitres of fuel.</p><p><em><strong>Fuel left: 21</strong></em></p><hr><p>Next it crosses <code>"Venus"</code>, losing another <code>4</code> megalitres of fuel.</p><p><em><strong>Fuel left: 17</strong></em></p><hr><p>Finally it has reached its destination planet, <code>"Neptune"</code>, but still needs to land. So it uses <code>2 * 7</code> megalitres, which is <code>14</code>.</p><p><em><strong>Fuel left: 3</strong></em></p><hr><p>Done! The spaceship landed on the <code>destination_planet</code> without running out of fuel and you just have to return <code>True</code>. Likewise, if the spaceship had only 20 megalitres it would not be able to make it and you would have to return <code>False</code> in that case.</p><p>In this case the <code>destination_planet</code>, <code>"Neptune"</code>, was on the right side of Earth in the list. If the <code>destination planet</code> is on the left side, the space ship simply moves in that direction. So, if the <code>destination_planet</code> for the exact same <code>solar_system</code> as above is <code>"Mercury"</code>, the spaceship would launch from <code>"Earth"</code>, cross the one <code>"Asteroid"</code> on <code>"Earth"</code>'s left, and then land on <code>"Mercury"</code>.</p><h2 id="notes">NOTES</h2><ol>  <li>The <code>fuel</code> integer passed will never be negetive, but it could be <code>0</code>, in which case any mission is doomed to fail.</li>  <li>If the spaceship lands on the destination planet with exactly <code>0</code> megalitres of fuel left, it is still successful and you should return <code>True</code>.</li>  <li>The <code>fuel_map</code> is given preloaded. You can use it directly in your code.</li>  <li>There will always be an <code>"Earth"</code> and the given <code>destination_planet</code> in the Solar System list, so it will never be empty or have only one planet.</li>  <li>There will always be zero or one of each planet. So there will never be two <code>"Earth"</code>s or two <code>"Jupiter"</code>s. There can be multiple <code>"Asteroid"</code>s though.</li>  <li>The <code>solar_system</code> input list should not be mutated.</li>  <li>All planet names and asteroids in the <code>solar_system</code> list or as the <code>destination_planet</code> will always be title-cased.</li>  <li>There will not be a Pluto in the Solar System.</li></ol><p>Good luck!
