<h2><a href=https://www.codewars.com/kata/6a784d563bfd7732517d9832/train/python target="_blank">Strings going down</a></h2><h3>7 kyu</h3><h1 id="words-down-the-page">Words Down the Page</h1><p>We normally read a list of words <strong>left to right</strong>:</p><pre><code>hi world yo</code></pre><p>Your job is to print them <strong>top to bottom</strong> instead.</p><p>Each word becomes a column exactly one character wide, running down the page.The columns keep their original order, sit side by side, and are separated by asingle space.</p><h2 id="example">Example</h2><pre><code class="language-python"><span class="cm-variable">vertical</span>([<span class="cm-string">"hi"</span>, <span class="cm-string">"world"</span>, <span class="cm-string">"yo"</span>])</code></pre><p>returns the string</p><pre><code>h w yi o o  r  l  d</code></pre><p><code>hi</code> and <code>yo</code> run out after two characters, so their columns simply go blank —but <code>world</code> keeps going, and it has to stay in the same column it started in.</p><h2 id="rules">Rules</h2><ul><li>Return a <strong>single string</strong>. Rows are joined with <code>"\n"</code>. There is <strong>no</strong>trailing newline.</li><li>The number of rows is the length of the longest word.</li><li>Where a word has run out of characters, its cell is blank. The columns to theright must still line up.</li><li>Every line is right-trimmed.</li><li>An empty word <code>""</code> still owns a column.</li><li>An empty list returns <code>""</code>.</li></ul><h2 id="guarantees">Guarantees</h2><ul><li>The input is a list of strings.</li><li>No word contains a space.</li><li>Words are made of letters (either case) and digits.</li></ul>
