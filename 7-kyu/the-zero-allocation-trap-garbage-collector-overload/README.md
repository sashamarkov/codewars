<h2><a href=https://www.codewars.com/kata/6a455b890c14d1b6e9e54a78/train/csharp target="_blank">The Zero-Allocation Trap: Garbage Collector overload</a></h2><h3>7 kyu</h3><h3 id="background">Background</h3><p>The Concurrent Spacecraft's telemetry module monitors vital statistics. To process these rapidly changing metrics, the system frequently calls a legacy utility method: <code>GetMaxAnomaly()</code>. </p><p>The current method accepts a variable number of arguments and calculates the maximum absolute difference (delta) between adjacent sensor readings. </p><h3 id="the-problem">The Problem</h3><p>The onboard Garbage Collector is being overwhelmed. An overwhelmed Garbage Collector triggers frequent "Stop-The-World" pauses, freezing all application threads to clean up the flooded heap memory. This causes massive CPU starvation and severe latency, completely blinding the spacecraft's telemetry system during critical orbital maneuvers. The Lead Architect has identified that the legacy <code>params int[]</code> method signature is silently allocating arrays on the heap millions of times per second. </p><p>The Architect wants you to fix the signature, leaving behind a note:</p><blockquote><p><em>"We just updated our systems to C# 13, we now have our chance! You must completely eliminate the array allocation from the signature. However, the rest of the system relies on passing comma-separated values, so <code>GetMaxAnomaly(10, 20, 30)</code> must still compile! We must allow for a variable arguments using a read-only, stack-allocated, contiguous region of memory. At the same time, we need a GetMinAnomaly method following the same requirements."</em></p></blockquote><p>Forgetting to mention anything more.</p><h3 id="the-requirements">The Requirements</h3><ol><li>You may only have exactly <strong>ONE</strong> method named <code>GetMaxAnomaly</code>. (Do not create method overloads to bypass the comma-separated requirement).</li><li>The method must continue to correctly calculate the maximum anomaly.</li><li>If less than 2 elements are provided, return <code>0</code>.</li><li><strong>No arrays allowed</strong> in the parameter signature.</li><li>The memory type you choose must be a <strong>stack-only structure</strong> (it cannot be placed on the heap) and must enforce <strong>read-only</strong> behavior on the data. </li><li><strong>Clean up the code:</strong> Stack-only structs shouldn't be compared to <code>null</code>. The Architect requires you to remove the legacy null check!</li><li><strong>Add <code>GetMinAnomaly</code>:</strong> The Architect wants a new method to track the minimum absolute difference between adjacent sensor readings. You must create this method from scratch using the exact same signature constraints.</li></ol>
