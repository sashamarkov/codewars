<h2><a href=https://www.codewars.com/kata/580627d7c3c7798449000183/train/c target="_blank">String: return formatted string</a></h2><h3>7 kyu</h3><p>Challenge:Given a buffer string, the length of the buffer string, the format string and the variable number of arguments, return a fully formatted string. The format rules are the same as those for the "printf" family of functions:</p><p><a href="http://www.cplusplus.com/reference/cstdio/printf/" data-turbolinks="false" target="_blank">http://www.cplusplus.com/reference/cstdio/printf/</a></p><p>However, for this kata, you surprisingly don't need any particular knowledge of these formatting rules. You are not required to reimplement the functionality, instead you should simply do some "re-routing".</p><p>Example:</p><pre><code>char buffer[SCHAR_MAX];size_t bufferLength = sizeof(buffer) / sizeof(buffer[0]);char *message = formatString(buffer, bufferLength, "%d bottles of %s!", 99, "Ovaltine");(void)puts(message); // outputs: 99 bottles of Ovaltine!</code></pre><p>Addendum:This kata is actually very simple. Hint: consult the C standard library documentation.</p><p>To successfully complete this challenge, you might want to be familiar with the <em>variable arguments</em> in C.</p><p>This kata does not require any memory allocation/de-allocation or error checking. You are guaranteed to receive valid parameters.</p>
