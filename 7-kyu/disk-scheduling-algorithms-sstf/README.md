<h2><a href=https://www.codewars.com/kata/63e50629be9fe90024f3a749/train/python target="_blank">Disk scheduling algorithms: SSTF</a></h2><h3>7 kyu</h3><p>Disk scheduling algorithms are techniques used by operating systems to determine the order in which read and write requests are serviced by a hard disk drive (HDD). Their primary objective is to reduce seek time, which is the time required for the disk head to move between tracks, thereby improving overall system performance and throughput.</p><h2 id="the-sstf-disk-scheduling-algorithm">The SSTF disk scheduling algorithm</h2><p>The shortest seek time first (SSTF) algorithm services the I/O request that is closest to the current position of the disk head. By always selecting the request with the shortest seek distance, it reduces the total head movement and generally provides better performance than other methods. However, requests that are far from the current head position may experience long waiting times, potentially leading to starvation.</p><p>Your task is to implement this algorithm. The function will take two parameters as input: a <code>request queue</code>, a list of integers representing the disk locations that must be accessed to fulfill the pending I/O requests, and the <code>initial head position</code>, an integer representing the starting position of the disk head. At each step, the function should select and service the pending request that is closest to the current head position. This process continues until all requests have been serviced. When two or more pending requests are at the same distance from the current head position, the algorithm should service the one that appears first in the request queue.</p><p>The expected output is the total head movement, represented as an integer corresponding to the sum of all head movements required to service the requests in the queue.</p><h2
