<h2><a href=https://www.codewars.com/kata/621e323a98afab001628d9a0/train/python target="_blank">Gambling Game Joker</a></h2><h3>6 kyu</h3><p>Popular gambling game <strong>Joker</strong> consists of drawing 6 balls from a drum on which are written numbersbetween 1 and 45. The winning joker number is formed from the drawn numbers so that in the same order in which the balls are drawn, we write down their last digits. </p><p>For example, if the numbers 12, 35, 1, 2, 23 and 39 are drawn in order, then it is a joker No. 251239. </p><p><code>1[2], 3[5], [1], [2], 2[3], 3[9] --&gt; 251239</code></p><p>Players buy winning tickets and look forward to drawing and calculating the joker number to calculate their possible gain. The winnings of the ticket are calculated by comparing the serial number written on the ticket with the calculated joker number in a way to count how many <em>last digits</em> of these two numbers match, as shown in the following table.</p><pre><code>Serial No. | Name of prize-----------+---------------251239     |   I typeX51239     |   II typeXX1239     |   III typeXXX239     |   IV typeXXXX39     |   V typeXXXXX9     |   Losing cardXXXXXX     |   Losing card</code></pre><p>In the left column are the serial numbers of the tickets, where X denotes arbitrary digits. In the right column of the table are the winnings names for each of the serial number forms. So if the serial number is exactly equal to the Joker number then we get the gain of type I, if the last 5 digits are equal we get the gain of type II, and so on, until the gain of type V, the kind we get when the last two digits are equal. All other serials are not winning.</p><p>Write a program that will return the names of the winnings for a given Joker number and given tickets. The names of the winnings must be written exactly as written in the table above (the number of winnings is written in Roman numbers with capital letters ‘I’ and ‘V’, followed by a space and lowercase letters ‘type’).</p><h2 id="input">Input</h2><p>joker_nums --&gt; an array of 6 numbers from which you have to make the winning Joker number</p><p>ticket_serials --&gt; an array of 3 ticket serial numbers</p><h2 id="output">Output</h2><p>You should return a list with the names of the winnings for the 3 given tickets</p><pre><code class="language-python"><span class="cm-variable">joker_card</span>([<span class="cm-number">12</span>, <span class="cm-number">35</span>, <span class="cm-number">1</span>, <span class="cm-number">2</span>, <span class="cm-number">23</span>, <span class="cm-number">39</span>], [<span class="cm-string">'151239'</span>, <span class="cm-string">'251229'</span>, <span class="cm-string">'251339'</span>]) <span class="cm-operator">-</span><span class="cm-operator">-</span><span class="cm-operator">&gt;</span> [<span class="cm-string">"II type"</span>, <span class="cm-string">"Losing card"</span>, <span class="cm-string">"V type"</span>]</code></pre><h2 id="note">Note</h2><ul><li>some tickets may have leading zeros</li><li>some joker numbers may have leading zeros</li><li>leading zeros still count towards the total</li></ul><p>Problem taken from the <a href="https://upinitk.ba/wp-content/uploads/2018/01/Bilten2016.pdf" data-turbolinks="false" target="_blank">Cantonal competition in Informatics 2016, Tuzla</a></p>
