<h2><a href=https://www.codewars.com/kata/602d1d769a1edc000cf59e4c/train/python target="_blank">Weather prediction</a></h2><h3>6 kyu</h3><p>Let there be <code>k</code> different types of weather, where we denote each type of weather by a positive integer. For example, sunny = 0, rainy = 1, ..., cloudy = k.</p><h3 id="task">Task</h3><p>Find the probability of having weather <code>j</code> in <code>n</code> days from now given weather <code>i</code> today and conditional on some daily weather transition probabilities, a <code>k*k</code> matrix, where <code>i</code> and <code>j</code> are integers less than or equal to <code>k</code>.</p><h3 id="example">Example</h3><p>There are two types of weather 0 and 1. Transition probabilities:</p><pre><code>[[0.6, 0.4], [0.3, 0.7]]</code></pre><ul><li>The probability of weather 0 tomorrow if weather 0 today: 60%</li><li>The probability of weather 1 tomorrow if weather 0 today: 40%</li><li>The probability of weather 0 tomorrow if weather 1 today: 30% </li><li>The probability of weather 1 tomorrow if weather 1 today: 70%</li></ul><p>The probability of weather 0 <em>two</em> days from now if we start in weather 0 becomes: 60% * 60% + 40% * 30% = 48%. Because either we stay in 0 for two days or we go from 0 to 1 and then from 1 to 0. </p><h3 id="note">Note</h3><p>We will have <code>k</code> ≤ 10 and <code>n</code> ≤ 50.</p>
