<h2><a href=https://www.codewars.com/kata/59eea9a13d09a75fd10002c5/train/javascript target="_blank">Simple Fun #369: Count Binary Substring I</a></h2><h3>6 kyu</h3><h1 id="task">Task</h1><p>Given two strings <code>s1</code> and <code>s2</code>, whose alphabet consist only 0 and 1. Your task is to count how many times <code>s1</code> appear as a substring in <code>s2</code>. </p><p>For example, if <code>s2</code> is <code>"1001110110"</code> while the pattern string <code>s1</code> is <code>"11"</code>, your output should be <code>3</code>, because the pattern <code>s1</code> 3 times appeared in <code>s2</code>.</p><p>Still don't understand the problem? Look at the following examples:</p><h1 id="examples">Examples</h1><p>For <code>s1 = "11", s2 = "1001110110"</code>, the output should be <code>3</code>.</p><p>Fisrt <code>s1</code> in <code>s2</code> -----&gt; "100<font color="red">11</font>10110"</p><p>Second <code>s1</code> in <code>s2</code>--&gt; "1001<font color="red">11</font>0110"</p><p>Third <code>s1</code> in <code>s2</code> ----&gt; "1001110<font color="red">11</font>0"</p><p>For <code>s1 = "101", s2 = "110010010010001"</code>, the output should be <code>0</code>.</p><p>There is no <code>s1</code> in <code>s2</code>.</p><p>For <code>s1 = "1010", s2 = "110100010101011"</code>, the output should be <code>3</code>.</p><p>Fisrt <code>s1</code> in <code>s2</code> -----&gt; "1<font color="red">1010</font>0010101011"</p><p>Second <code>s1</code> in <code>s2</code>--&gt; "1101000<font color="red">1010</font>1011"</p><p>Third <code>s1</code> in <code>s2</code> ----&gt; "110100010<font color="red">1010</font>11"</p><h1 id="note">Note</h1><ul><li><p><code>2 &lt;= s1.length &lt;=10</code></p></li><li><p><code>10 &lt;= s2.length &lt;=1000000</code></p></li><li><p>Happy Coding <code>^_^</code></p></li></ul>
