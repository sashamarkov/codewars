<h2><a href=https://www.codewars.com/kata/560030c3ab9f805455000098/train/python target="_blank">Put the cat on the table</a></h2><h3>6 kyu</h3><p>The cat wants to lay down on the table, but the problem is that we don't know where it is in the room!</p><p>You'll get in input:</p><ul><li>the cat coordinates as a list of length 2, with the row on the map and the column on the map.</li><li>the map of the room as a list of lists where every element can be 0 if empty or 1 if is the table (there can be only one 1 in the room / lists will never be empty).</li></ul><h1 id="task">Task:</h1><p>You'll need to return the route to the table, beginning from the cat's starting coordinates, as a String. The route must be a sequence of letters U, D, R, L that means Up, Down, Right, Left. The order of the letters in the output isn't important.</p><h1 id="outputs">Outputs:</h1><ul><li>The route for the cat to reach the table, as a string</li><li>If there isn't a table in the room you must return "NoTable"</li><li>if the cat is outside of the room you must return "NoCat" (this output has the precedence on the above one).</li><li>If the cat is alredy on the table, you can return an empty String.</li></ul><h1 id="example">Example:</h1><pre><code>cat = [0,1]room =[[0,0,0], [0,0,0], [0,0,1]]The route will be "RDD", or "DRD" or "DDR"</code></pre>
