<h2><a href=https://www.codewars.com/kata/5ecc16daa200d2000165c5b1/train/javascript target="_blank">Increment with iterations</a></h2><h3>6 kyu</h3><p>Your goal in this kata is to implement an algorithm, which increases <code>number</code> in the way explained below, and returns the result.</p><p>Input data: <code>number, iterations, step</code>.</p><p>Stage 1:</p><p>We get the: <code>number:143726</code>, <code>iterations:  16</code>, <code>step:3</code></p><p>And make increment operations in a special way</p><p>Position: We start from <code>1</code> position and increment <code>4</code>th num, besause <code>step</code> is <code>3</code></p><p><code>s</code> - start position</p><p><code>+</code> - current increased position</p><p>Position: <code>s - - - - -</code> =&gt; <code>- - - + - -</code></p><p>Number: <code>1 4 3 7 2 6</code> =&gt; <code>1 4 3 8 2 6</code></p><p>Stage 2: repeat stage 1 :)</p><p>Position: <code>- - - s - -</code> =&gt; <code>+ - - - - -</code></p><p>Number: <code>1 4 3 8 2 6</code> =&gt; <code>2 4 3 8 2 6</code></p><p>You must remember: if your number overflow into a longer number, the current position gets shifted to the right</p><p><code>9 9 9</code> =&gt; <code>- - p</code> - before overflow position be at <code>3</code>rd digit</p><p><code>1 0 0 0</code> =&gt; <code>- - - p</code> - after overflow position be at <code>4</code>th digit</p><p>Note:</p><p><code>9 =&gt; 10</code></p><p><code>799 =&gt; 800</code> (if you increase second <code>9</code>) or <code>809</code> (if you increase first <code>9</code>)</p><p><code>99000 =&gt; 100000</code> (if you increase second <code>9</code>) or <code>109000</code> (if you increase first <code>9</code>)</p>
