<h2><a href=https://www.codewars.com/kata/5ac66185a1ad6f065b000046/train/javascript target="_blank">Clean up your Gibberish!</a></h2><h3>6 kyu</h3><p>We've begun receiving transmissions from Planet Gibber again after many decades of silence. Unfortunately, this time they've been all garbled up! </p><p>Luckily, linguists were able to figure out the rules of Gibberish the last time we heard from them. They've given us a guide on how to identify the actual bits of language from the random data in the strings we receive.</p><p>In order to parse the Gibberish from the... well, <em>gibberish</em>, we'll need to follow these rules:</p><ul><li>Gibberish, as we read it, only contains letters: remove all non-letter characters (including spaces)</li><li>Gibberish is only made up of 5 letter words: separate this into words that are all 5 letters long - no trailing words with fewer than 5 letters!</li><li>Gibberish word are all capitalised: so capitalise all the words (sort of like German nouns)</li></ul><p>Some of the transmissions are only garbled data. If you are given an empty string or a string that doesn't contain any letters, then please return an empty string at the end.</p><p>Even if you can't read the Gibberish, that's okay as long as you've formatted it according to the language rules!</p><p>Good luck :)</p>
