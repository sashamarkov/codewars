<h2><a href=https://www.codewars.com/kata/575951d3961a030cb1000841/train/javascript target="_blank">Building a mini search engine</a></h2><h3>6 kyu</h3><p>Build a mini search engine by writing a function that takes four parameters: (1) a string, (2) a word to search for, (3) a search method and (possibly) (4) a new word. </p><p>The string can contain any characters (alphanumeric and/or symbols), the words (both <code>searchWord</code> and <code>newWord</code>) can contain only letters and/or numbers and the search method can only take two numbers: <code>1</code> for searching for a specific word only and <code>2</code> for searching and replacing each occurrence of a specific word. The default search method is <code>1</code>.</p><p>The function should return an object with two properties called <code>matches</code> and <code>newString</code>.</p><p>If the search method is set to <code>1</code>, the <code>matches</code> property should be equal to the number of matches and the <code>newString</code> property should be equal to the empty string. If the search method is <code>2</code>, the <code>matches</code> property should be the number of replacements and the <code>newString</code> should be the new string where all the matches are replaced with the new word. </p><p>The function should be case sensitive. If invalid input is entered, return 'No valid input'. </p><p>Let's see some examples:</p><pre><code class="language-javascript"><span class="cm-variable">searchEng</span>(<span class="cm-string">'OMG, today is Monday!'</span>,<span class="cm-string">'day'</span>, <span class="cm-number">1</span>); <span class="cm-comment">// should return {matches: 0, newString: ''}</span><span class="cm-variable">searchEng</span>(<span class="cm-string">'Today is my day!'</span>,<span class="cm-string">'day'</span>, <span class="cm-number">2</span>, <span class="cm-string">'birthday'</span>); <span class="cm-comment">// should return {matches: 1, newString: 'Today is my birthday!'}</span><span class="cm-variable">searchEng</span>(<span class="cm-string">'Today is my day.'</span>,<span class="cm-string">'day.'</span>, <span class="cm-number">2</span>, <span class="cm-string">'birthday!'</span>); <span class="cm-comment">// should return 'No valid input'  </span></code></pre><p>Enjoy:)</p>
