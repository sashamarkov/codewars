<h2><a href=https://www.codewars.com/kata/599c7f81ca4fa35314000140/train/python target="_blank">n-back</a></h2><h3>6 kyu</h3><p>From <a href="https://en.wikipedia.org/wiki/N-back" data-turbolinks="false" target="_blank">Wikipedia</a>: "The n-back task is a continuous performance task that is commonly used as an assessment in cognitive neuroscience to measure a part of working memory and working memory capacity. [...] The subject is presented with a sequence of stimuli, and the task consists of indicating when the current stimulus matches the one from <code>n</code> steps earlier in the sequence. The load factor <code>n</code> can be adjusted to make the task more or less difficult."</p><p>In this kata, your task is to "teach" your computer to do the n-back task.<br>Specifically, you will be implementing a function that counts the number of "targets" (stimuli that match the one from <code>n</code> steps earlier) in a sequence of digits.</p><p>Your function will take two parameters:</p><ul><li><code>n</code>, a positive integer: the number of steps to look back to find a match</li><li><code>sequence</code>, a sequence of digits containing <code>0</code> or more targets</li></ul><p>A few hints:</p><ul><li>The first digit in a sequence can never be a target</li><li>Targets can be "chained" together (e.g., for <code>n = 1</code> and <code>sequence = [1, 1, 1]</code>, there are <code>2</code> targets)</li></ul>
