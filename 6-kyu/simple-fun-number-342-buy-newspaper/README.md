<h2><a href=https://www.codewars.com/kata/596c26187bd547f3a6000050/train/python target="_blank">Simple Fun #342: Buy Newspaper</a></h2><h3>6 kyu</h3><h1 id="task">Task</h1><p>A newspaper is published in Walrusland. Its heading is <code>s1</code> , it consists of lowercase Latin letters. </p><p>Fangy the little walrus wants to buy several such newspapers, cut out their headings, glue them one to another in order to get one big string. </p><p>After that walrus erase several letters from this string in order to get a new word <code>s2</code>. </p><p>It is considered that when Fangy erases some letter, there's no whitespace formed instead of the letter. That is, the string remains unbroken and it still only consists of lowercase Latin letters.</p><p>For example, the heading is <code>"abc"</code>. If we take two such headings and glue them one to the other one, we get <code>"abcabc"</code>. If we erase the 1st letter("a") and 5th letter("b"), we get a word <code>"bcac"</code>.</p><p>Given two string <code>s1</code> and <code>s2</code>, return the least number of newspaper headings <code>s1</code>, which Fangy will need to receive the word <code>s2</code>. If it is impossible to get the word <code>s2</code> in the above-described manner, return <code>-1</code>.</p><h1 id="example">Example</h1><p>For <code>s1="abc", s2="bcac"</code>, the output should be <code>2</code>.</p><pre><code>"abcabc" --&gt; "bcac" x   x</code></pre><p>For <code>s1="abc", s2="xyz"</code>, the output should be <code>-1</code>.</p><p>It's impossible to get the word <code>s2</code>.</p>
