<h2><a href=https://www.codewars.com/kata/60b7d7c82358010006c0cda5/train/python target="_blank">Corner Fill</a></h2><h3>6 kyu</h3><h1 id="corner-fill">Corner Fill</h1><p>You receive a two dimensional array of size <code>n x n</code> and you want to fill in the square in one stroke while starting from <code>0:0</code> and ending on <code>n-1:0</code>.</p><p>If <code>n = 3</code> then:</p><pre><code class="language-rb">[  [1, 2, 3],  [4, 5, 6],  [7, 8, 9]]</code></pre><p>Starting from left to right and then top to bottom we can grab the first corner! We then return on the inside of this corner to get the next one, and so on (see image below).</p><img src="https://files.gitter.im/55db43670fc9f982beae700d/koKc/corners.svg" style="background-color:white;" width="155"><p>Resulting in the sequence <code>[1, 2, 3, 6, 9, 8, 5, 4, 7]</code>.</p><p>Another example:</p><pre><code class="language-rb"># 4x4 (Mixed numbers)[  [4,  1, 10,  5],  [7,  8,  2, 16],  [15, 14, 3,  6],  [11, 9, 13, 12]]#=&gt; [4, 1, 10, 5, 16, 6, 12, 13, 3, 2, 8, 7, 15, 14, 9, 11]</code></pre><h3 id="inputs">Inputs</h3><p>The input array can be of size <code>n=0</code>, in which case we want to return <code>[]</code></p>
