<h2><a href=https://www.codewars.com/kata/5d41d87bb29859002690d4fd/train/python target="_blank">Counting Digits</a></h2><h3>6 kyu</h3><p><em>This kata is inspired by the British gameshow Only Connect, specifically the clue that stumped the contestants <a href="https://youtu.be/eP45h03_QYs?t=732" data-turbolinks="false" target="_blank">seen here</a></em></p><p>Your goal is to write a function that receives an integer and then repeatedly counts the occurrences of each digit (the number of rounds will be given as a positive integer).</p><h4 id="note">Note</h4><p>The order is important, the result should list the digits in the order they first appeared (from left to right).</p><h2 id="examples">Examples</h2><h4 id="simple-1-round-example">Simple 1 round example:</h4><pre><code class="language-ruby"><span class="cm-variable">num</span> <span class="cm-operator">=</span> <span class="cm-number">141</span>, <span class="cm-variable">rounds</span> <span class="cm-operator">=</span> <span class="cm-number">1</span><span class="cm-tag">ROUND</span> <span class="cm-number">1</span><span class="cm-operator">:</span> <span class="cm-number">141</span> <span class="cm-operator">--&gt;</span> [<span class="cm-number">21</span>, <span class="cm-number">14</span>]<span class="cm-comment"># Reading left to right, 1 was encountered first (two 1), then 4 (one 4)</span></code></pre><p>So the solution is <code>[21, 14]</code></p><h4 id="simple-1-round-example-with-a-larger-number">Simple 1 round example with a larger number:</h4><pre><code class="cm-operator">=</span> <span class="cm-number">1</span><span class="cm-tag">ROUND</span> <span class="cm-number">1</span><span class="cm-operator">:</span> <span class="cm-number">1221313</span> <span class="cm-operator">--&gt;</span> [<span class="cm-number">31</span>, <span class="cm-number">22</span>, <span class="cm-number">23</span>]<span class="cm-comment"># Reading left to right, 1 was encountered first, then 2, then 3</span></code></pre><p>So the solution is <code>[31, 22, 23]</code></p><h4 id="more-complex-3-round-example">More complex 3 round example:</h4><pre><code
