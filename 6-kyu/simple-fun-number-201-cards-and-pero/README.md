<h2><a href=https://www.codewars.com/kata/58fd4bbe017b2ed4e700001b/train/python target="_blank">Simple Fun #201: Cards And Pero</a></h2><h3>6 kyu</h3><h1 id="task">Task</h1><p> Pero has been into robotics recently, so he decided to make a robot that checks whether a deck of poker cards is complete.</p><p> He’s already done a fair share of work - he wrote a programme that recognizes the suits of the cards. For simplicity’s sake, we can assume that all cards have a suit and a number.</p><p> The suit of the card is one of the characters <code>"P", "K", "H", "T"</code>, and the number of the card is an integer between <code>1</code> and <code>13</code>. The robot labels each card in the format <code>TXY</code> where <code>T</code> is the suit and <code>XY</code> is the number. If the card’s number consists of one digit, then X = 0. For example, the card of suit <code>"P"</code> and number <code>9</code> is labelled <code>"P09"</code>.</p><p> A complete deck has <code>52</code> cards in total. For each of the four suits there is exactly one card with a number between <code>1</code> and <code>13</code>.</p><p> The robot has read the labels of all the cards in the deck and combined them into the string <code>s</code>.</p><p> Your task is to help Pero finish the robot by writing a program that reads the string made out of card labels and returns the number of cards that are missing for each suit.</p><p> If there are two same cards in the deck, return array with <code>[-1, -1, -1, -1]</code> instead.</p><h1 id="inputoutput">Input/Output</h1><ul><li><code>[input]</code> string <code>s</code></li></ul><p>  A correct string of card labels. 0 ≤ |S| ≤ 1000</p><ul><li><code>[output]</code> an integer array</li></ul><p>  Array of four elements, representing the number of missing card of suits <code>"P", "K", "H", and "T"</code> respectively. If there are two same cards in the deck, return <code>[-1, -1, -1, -1]</code> instead.</p><h1 id="example">Example</h1><p> For <code>s = "P01K02H03H04"</code>, the output should be <code>[12, 12, 11, 13]</code>.</p><p> <code>1</code> card from <code>"P"</code> suit, <code>1</code> card from <code>"K"</code> suit, <code>2</code> cards from <code>"H"</code> suit, no card from <code>"T"</code> suit.</p><p> For <code>s = "H02H10P11H02"</code>, the output should be <code>[-1, -1, -1, -1]</code>.</p><p> There are two same cards <code>"H02"</code> in the string <code>s</code>.</p>
