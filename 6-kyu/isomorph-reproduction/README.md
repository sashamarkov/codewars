<h2><a href=https://www.codewars.com/kata/6a65304edd4cb60a90815a83/train/javascript target="_blank">Isomorph Reproduction</a></h2><h3>6 kyu</h3><h3 id="what-is-an-isomorph">What is an Isomorph?</h3><p>An <strong>isomorph</strong> is a string where the letters follow the exact same structural pattern. For example, <code>look</code> and <code>meet</code> are isomorphs because they both follow the pattern <code>ABBC</code>.</p><hr><h3 id="quick-summary">Quick Summary</h3><p>Using the pool of characters from <code>letters</code>,recreate the exact structural fingerprint found in <code>original</code>.</p><p><code>(original, letters) -&gt; solution</code></p><hr><h3 id="step-by-step-examples">Step-by-Step Examples</h3><p><strong>Example 1:</strong><code>("ggd", "vcv") -&gt; "vvc"</code></p><p><strong>Example 2:</strong><code>("aba", "xtt") -&gt; "txt"</code></p><p><strong>Example 3 (The Dilemma):</strong><code>("zyxx", "acba") -&gt; "cbaa"</code>But wait, <code>("zyxx", "acba") -&gt; "bcaa"</code> is also a valid structural match! </p><p>When different letters share the exact same frequency count, multiple solutions are possible because the letters are able to trade positions.</p><p><strong>The Tie-Breaker Rule:</strong>Solve this dilemma by sorting those competing letters <strong>alphabetically</strong> before assigning them. Therefore, the only correct solution is:<code>("zyxx", "acba") -&gt; "bcaa"</code></p><hr><h3 id="rules-of-engagement">Rules of Engagement</h3><ol><li><strong>Frequency Matching:</strong> Letters must pair with target characters of identical frequency.</li><li><strong>Order of Appearance:</strong> Map remaining characters based on their original left-to-right appearance.</li><li><strong>Alphabetical Tie-Breaker:</strong> Sort same-frequency pool letters alphabetically.</li><li><strong>Invalid States:</strong> Return null if a match is mathematically impossible (e.g., length mismatch).</li></ol><hr><h3 id="input-constraints">Input Constraints</h3><ul><li>Both inputs will contain <strong>only</strong> lowercase alphabetic letters (<code>a-z</code>).</li><li><code>letters</code> is the only input that might have the wrong length, missing characters, or a distribution that cannot mathematically map to <code>original</code>.</li></ul>
