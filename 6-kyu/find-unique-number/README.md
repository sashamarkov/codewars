<h2><a href=https://www.codewars.com/kata/5822d900b81f701dd40002c9/train/javascript target="_blank">Find unique number</a></h2><h3>6 kyu</h3><blockquote><p>When no more interesting kata can be resolved, I just choose to create the new kata, to solve their own, to enjoy the process  --myjinxin2015 said</p></blockquote><h1 id="description">Description:</h1><p> Give you a array <code>arr</code> that contains some numebers. Numbers can be positive,negative,integer or float. Only one of these numbers is unique. Find and return it.</p><h1 id="some-examples">Some examples:</h1><pre><code>findUnique([1,2,3,5,7]) === 2Because only 2 is an even number, the other numbers are odd.findUnique([2,4,6,8,9]) === 9Because only 9 is an odd numberfindUnique([2,-4,6,8]) === -4Because only -4 is a negative numberfindUnique([-2,-4,-6,8]) === 8Because only 8 is a positive numberfindUnique([2,4.4,6,8]) === 4.4Because only 4.4 is a float numberfindUnique([2.2,4.4,6.6,8]) === 8Because only 8 is a integer numberfindUnique([2,2,2,4]) === 4Because only 4 has a diffrent value</code></pre><p> Priority level: float/integer &gt; positive/negative &gt; odd/even &gt; diffrent value</p><p> Some edge case:</p><pre><code>findUnique([-2,-4,-6.6,8]) === -6.6  //not 8Because Priority level float/integer &gt; positive/negativefindUnique([-2,-4,-7, 8]) === 8  //not -7Because Priority level positive/negative &gt; odd/even</code></pre><p> Note: All inputs will be an array. The array contains at least 3 element. Only one unique number in it. 0 will not appear, do not worry about it ;-)</p>
