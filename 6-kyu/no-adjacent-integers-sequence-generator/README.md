The minimum sequence length tested is <em>long enough.</em></p><h4 id="examples">Examples</h4><p>For <code>solution(0,6)</code>: <code>5,0,4,1,3,2</code> would not be acceptable, because <code>3</code> and <code>2</code> are adjacent. <code>0,2,5,3,1,4</code> would be acceptable.</p>
