<h2><a href=https://www.codewars.com/kata/58901ac726bd581274000096/train/python target="_blank">Doubly Linked List</a></h2><h3>6 kyu</h3><h1 id="linked-list">Linked List</h1><p>Implement a doubly linked list</p><p>Like an array, a linked list is a simple linear data structure. Severalcommon data types can be implemented using linked lists, like queues,stacks, and associative arrays.</p><p>A linked list is a collection of data elements called <em>nodes</em>. In a<em>singly linked list</em> each node holds a value and a link to the next node.In a <em>doubly linked list</em> each node also holds a link to the previousnode.</p><p>You will write an implementation of a doubly linked list. Implement aNode to hold a value and pointers to the next and previous nodes. Thenimplement a List which holds references to the first and last node andoffers an array-like interface for adding and removing items:</p><ul><li><code>push</code> (<em>insert value at back</em>);</li><li><code>pop</code> (<em>remove value at back</em>);</li><li><code>shift</code> (<em>remove value at front</em>).</li><li><code>unshift</code> (<em>insert value at front</em>);</li></ul><p>To keep your implementation simple, the tests will not cover errorconditions. Specifically: <code>pop</code> or <code>shift</code> will never be called on anempty list.</p><p>If you want to know more about linked lists, check <a href="https://en.wikipedia.org/wiki/Linked_list" data-turbolinks="false" target="_blank">Wikipedia</a>.</p><h2 id="source">Source</h2><p>Classic computer science topic</p>
