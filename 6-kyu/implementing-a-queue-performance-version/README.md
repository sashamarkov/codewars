<h2><a href=https://www.codewars.com/kata/5a8bd383fd8c0664190000b6/train/javascript target="_blank">Implementing a Queue - Performance Version</a></h2><h3>6 kyu</h3><p>This kata is based on the kata <a href="https://www.codewars.com/kata/implementing-a-queue" data-turbolinks="false" target="_blank">Implementing a Queue</a> by <a href="https://www.codewars.com/users/fvcproductions" data-turbolinks="false" target="_blank">fvproductions</a>. However, this kata suggests implementing a queue using an array and prepending and popping values. Since prepending values to an array requires the entire array to be rewritten, this can be very slow for large queues.</p><h2>Task</h2><p>Implement a queue which can enqueue and dequeue values in <em>constant</em> (O(1)) time. That is, regardless of how many items are currently in a queue, adding or removing a value takes the same amount of time.</p><p>As long as the specifications are followed, any implementation is acceptable.</p><h3>Specifications</h3><ul><li>Queue represents a "First-in, first-out" data structure in which items can be added using the "enqueue" method, and removed using the "dequeue" method. For example, if 1, 2, and 3 are added in three successive calls to "enqueue," 1 will be returned on the next call to "dequeue."</li><li>Queue's constructor takes no arguments.</li><li>Queue contains no static methods, and 3 prototype methods: "enqueue", "dequeue", "size."</li><li>Queue.prototype.enqueue takes one argument of any type and adds it to the queue in O(1) time.</li><li>Queue.prototype.dequeue takes no arguments and removes and returns the first item in the Queue in O(1) time. If no items are in the queue, this method returns <code>undefined</code>.</li><li>Queue.prototype.size returns how many items are currently held in the queue in O(1) time.</li></ul>
