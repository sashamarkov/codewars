If we change the position of the digits of n, we may obtain another perfect square<code> 625</code> (square root = 25).With these three digits <code>2</code>,<code>5</code> and <code>6</code> we can get two perfect squares: <code>[256,625]</code></p><p>The number <code>1354896</code> may generate another <code>4</code> perfect squares, having with the number itself, a total of five perfect squares: <code>[1354896, 3594816, 3481956, 5391684, 6395841]</code>, being the last one in the list, <code>6395841</code>, the highest value of the set.</p><p>Your task is to find the first perfect square above the given lower_limit, that can generate the given k number of perfect squares, and it doesn't contain the digit 0. Then return the maximum perfect square that can be obtained from its digits.</p><p>Example with the cases seen above:</p><pre><code>lower_limit = 200k = 2 (amount of perfect squares)result = 625lower_limit = 3550000k = 5 (amount of perfect squares)result  = 6395841</code></pre><p>Features of the random tests:</p><pre><code>100 &lt;= lower_limit &lt;= 1e62 &lt;= k &lt;= 5number of tests = 45</code></pre><p>Have a good time!</p>
