<h2><a href=https://www.codewars.com/kata/58efb6ef0849132bf000008f/train/python target="_blank">Palindrome Builder</a></h2><h3>6 kyu</h3><h2 id="task">Task</h2><p>Given a string, add the fewest number of characters possible from the front or back to make it a palindrome.</p><h2 id="example">Example</h2><p>For the input <code>cdcab</code>, the output should be <code>bacdcab</code></p><h2 id="inputoutput">Input/Output</h2><p>Input is a string consisting of lowercase latin letters with length 3 &lt;= str.length &lt;= 10</p><p>The output is a palindrome string satisfying the task.</p><p>For s = <code>ab</code> either solution (<code>aba</code> or <code>bab</code>) will be accepted.</p>
