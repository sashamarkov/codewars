<h2><a href=https://www.codewars.com/kata/577bd442df78c172af0002f8/train/javascript target="_blank">T.T.T.15: Sort the alarm clock</a></h2><h3>6 kyu</h3><h2 id="task">Task</h2><p>John set up a lot of alarm clocks on his cell phone. Please sort these alarm clocks follow the order of the next ring time.</p><h2 id="rules">Rules</h2><p><code>argument 1: alarm</code>, a list of alarm clocks. Given by an array, each element is an object. For example:</p><pre><code>[{name:"get up", time:"07:00",frequency:"every day"},{name:"go to work", time:"09:00",frequency:"every workday"},{name:"bodybuilding",   time:"10:00",frequency:"every saturday"},{name:"date girlfriend",time:"18:00",frequency:"only once"}]</code></pre><p>frequency has four types:</p><p><code>every day</code> means that the alarm clock will rings every day.</p><p><code>every workday</code> means that alarm clock only in John's working day will ring(from monday to friday).</p><p><code>every .....day</code> means that alarm clock every week only on a specific day will ring.</p><p><code>only once</code> means that alarm clock will only ring once in the specified time(must be later than or equals to the current time, today or tomorrow).</p><p><code>argument 2: time</code>, current time. Given by a string. For example:</p><pre><code>"2016-07-06 14:03" YYYY-MM-DD hh:mm</code></pre><p>You need to follow the current <code>time</code> and return a sorted array.</p><p>Such as the example above, you should return:</p><pre><code>[{name:"date girlfriend",time:"18:00",frequency:"only once"},{name:"get up",time:"07:00",frequency:"every day"},{name:"go to work",time:"09:00",frequency:"every workday"},{name:"bodybuilding",time:"10:00",frequency:"every saturday"}]</code></pre><p>Please see more example in testcases.</p>
