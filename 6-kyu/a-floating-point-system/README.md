<h2><a href=https://www.codewars.com/kata/5df754981f177f0032259090/train/python target="_blank">A floating-point system</a></h2><h3>6 kyu</h3><p>A ﬂoating-point number can be represented as <code>mantissa * radix ^ exponent</code> (^ is raising radix to power exponent).In this kata we will be given a positive floating-point number <code>aNumber</code> and we want to decompose it into a positive integer <code>mantissa</code> composed of a given number of digits (called <code>digitsNumber</code>) and of an <code>exponent</code>.</p><h4 id="example">Example:</h4><p><code>aNumber = 0.06</code></p><p>If the number of digits asked for the <code>mantissa</code> is <code>digitsNumber = 10</code>one can write </p><pre><code>aNumber : 6000000000 * 10 ^ -11</code></pre><p>the exponent in this example est <code>-11</code>.</p><h4 id="task">Task</h4><p>The function <code>mantExp(aNumber, digitsNumber)</code> will return <code>aNumber</code> in the form of a string: "mantissaPexponent" (concatenation of "mantissa", "P", "exponent"). So:</p><h3 id="examples">Examples:</h3><pre><code>mantExp(0.06, 10) returns "6000000000P-11".mantExp(72.0, 12)   returns "720000000000P-10"mantExp(1.0, 5) returns "10000P-4"mantExp(123456.0, 4) returns "1234P2"</code></pre><h4 id="notes">Notes:</h4><ul><li>In some languages <code>aNumber</code> could be given in the form of a string:<pre><code>mantExp("0.06", 10) returns "6000000000P-11".</code></pre></li><li>1 &lt;= digitsNumber &lt;= 15</li><li>0 &lt; aNumber &lt; 5.0 ^ 128</li><li>Please ask before translating</li></ul>
