<h2><a href=https://www.codewars.com/kata/5562aa03004710f3ab0001d5/train/python target="_blank">Connecting Values</a></h2><h3>5 kyu</h3><p>Given a two-dimensional array of non negative integers <code>arr</code>, a value <code>val</code>, and a coordinate <code>coord</code> in the form <code>(row, column)</code>, return an iterable (depending on the language) of all of the coordinates that contain the given value and are connected to the original coordinate by the given value.<br>A connection to the original coordinate is considered valid as long as there is a path of <strong>pairwise</strong> connected cells, horizontally, vertically, or diagonally.</p><p>If the value of <code>arr</code> at <code>coord</code> is not equal to <code>val</code>, return an empty iterable. The coordinates must include the original coordinate and may be in any order.</p><h2 id="examples">Examples:</h2><p>With the following array:</p><pre><code>    [1,0,2,0,2,1]    [1,0,2,1,5,7]    [4,1,1,0,1,9]</code></pre><p>With val <code>1</code> and coord <code>(0, 0)</code>, the output should contain (the order doesn't matter and the actual data structure depends on the language):</p><pre><code>[(2, 4), (2, 1), (0, 0), (2, 2), (1, 0), (1, 3)]</code></pre><p>With value <code>2</code> and coord <code>(0, 2)</code>:</p><pre><code>[(0, 2), (1, 2)]</code></pre><p>With value <code>0</code> and coord <code>(0, 0)</code>, the output should be empty.</p>
