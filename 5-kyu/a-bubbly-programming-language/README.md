<h2><a href=https://www.codewars.com/kata/5f7a715f6c1f810017c3eb07/train/python target="_blank">A Bubbly Programming Language</a></h2><h3>5 kyu</h3><p>Your goal is to make a stack based programming language with the following functions/tokens:</p><ul><li><code>start</code> - Marks the start of the program.</li><li><code>end</code> - Marks the end of the program, and returns the top element in the stack.</li><li><code>push x</code> - Pushes the integer <code>x</code> into the stack.</li><li><code>add</code> - Adds together the top two elements on the stack.</li><li><code>sub</code> - Subtracts the top-most element by the second top-most element on the stack.</li><li><code>mul</code> - Multiplies the top two elements on the stack.</li><li><code>div</code> - Divides (integer division) the top-most element by the second top-most element on the stack.</li></ul><p>Demo:</p><pre><code class="language-bubbly">   start push 5 push 3 add end = 8</code></pre><pre><code class="language-bubbly">   start push 2 push 5 div push 3 push 8 mul mul end = 48</code></pre><p>Easy, right?</p><p>Such a trivial string interpreter is probably too simple for an amazing code warrior like you. To spice things up, we will add bubbles into the mix. Each token must be engulfed by a bubble (parentheses)!</p><p>The syntax should be like:</p><pre><code class="language-bubbly">(start)(push)(4)(push)(9)(div)(end)</code></pre><p>which returns <code>2</code> in this case.</p><h2 id="task">Task</h2><p>Your goal is to create appropriate definitions for <code>start</code>, <code>end</code>, <code>push</code>, <code>add</code>, <code>sub</code>, <code>mul</code> and <code>div</code> so that the bubbly language is valid Python syntax, and evaluates to the correct value.</p><p>For instance, typing this in a shell should result in:</p><pre><code class="language-bubbly">&gt;&gt;&gt; (start)(push)(5)(push)(8)(push)(1)(add)(add)(end)14</code></pre><p>See the example tests for more examples.</p><h2 id="notes">Notes</h2><ul><li>Your definitions should allow multiple bubbly language statements in one script (python session).</li></ul><ul><li><p>Don't worry about division by <code>0</code>. There won't be any test cases on that.</p></li><li><p>All input will be valid.</p></li></ul><p>This kata is inspired by <a href="https://www.codewars.com/kata/55a4de202949dca9bd000088" data-turbolinks="false" target="_blank">A Simple Postfix Language</a>.</p>
