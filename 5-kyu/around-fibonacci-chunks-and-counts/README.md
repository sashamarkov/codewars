<h2><a href=https://www.codewars.com/kata/59bf943cafcda28e31000130/train/python target="_blank">Around Fibonacci: chunks and counts</a></h2><h3>5 kyu</h3><p>Another Fibonacci... yes but with other kinds of result.The function is named <code>aroundFib</code> or <code>around_fib</code>, depending of the language.Its parameter is <code>n</code> (positive integer).</p><p>First you have to calculate <code>f</code> the value of <code>fibonacci(n)</code> with <code>fibonacci(0) --&gt; 0</code> and<code>fibonacci(1) --&gt; 1</code> (see: <a href="https://en.wikipedia.org/wiki/Fibonacci_number" data-turbolinks="false" target="_blank">https://en.wikipedia.org/wiki/Fibonacci_number</a>)</p><ul><li><ol><li>Find the count of each digit <code>ch</code> in <code>f</code> (<code>ch</code>: digit from 0 to 9), call this value <code>cnt</code> and find the maximum value of cnt; call this maximum value <code>maxcnt</code>. If there are ties, the digit <code>ch</code> to consider is the first one - in natural digit order - giving <code>maxcnt</code>.</li></ol></li><li><ol start="2"><li>Cut the value <code>f</code> into chunks of length at most <code>25</code>. The last chunk may be 25 long or less.</li></ol></li></ul><pre><code>Example: for `n=100` you have only one chunk `354224848179261915075`Example: for `n=180` f is `18547707689471986212190138521399707760` and you have two chunks `1854770768947198621219013` and `8521399707760`. First length here is 25 and second one is 13.</code></pre><ul><li>At last return a string in the following format:"Last chunk ...; Max is ... for digit ..."</li></ul><p>where Max is <code>maxcnt</code> and digit the first <code>ch</code> (in 0..9) leading to <code>maxcnt</code>.</p><pre><code>Example: for `n=100` -&gt; "Last chunk 354224848179261915075; Max is 3 for digit 1" Example: for `n=180` -&gt; "Last chunk 8521399707760; Max is 7 for digit 7"Example: for `n=18000` -&gt; "Last chunk 140258776000; Max is 409 for digit 1"</code></pre><h4 id="beware">Beware:</h4><p><code>fib(18000)</code> has <code>3762</code> digits. Values of <code>n</code> are between <code>500</code> and <code>25000</code>.</p><h4 id="note">Note</h4><p>Please maybe ask before translating.</p>
