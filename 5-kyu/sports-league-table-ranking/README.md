<h2><a href=https://www.codewars.com/kata/5e0baea9d772160032022e8c/train/python target="_blank">Sports League Table Ranking</a></h2><h3>5 kyu</h3><p><em>Note: There is a harder version (<a href="https://www.codewars.com/kata/5e0e17220d5bc9002dc4e9c4" data-turbolinks="false" target="_blank">Sports League Table Ranking (with Head-to-head)</a>) of this.</em></p><h1 id="description">Description</h1><p>You organize a sports league in a <a href="https://en.wikipedia.org/wiki/Round-robin_tournament" data-turbolinks="false" target="_blank">round-robin-system</a>. Each team meets all other teams. In your league a win gives a team <code>2 points</code>, a draw gives both teams <code>1 point</code>. After some games you have to compute the order of the teams in your league. You use the following criteria to arrange the teams:</p><ul><li>Points</li><li>Scoring differential (the difference between goals scored and those conceded)</li><li>Goals scored</li></ul><p>First you sort the teams by their points. If two or more teams reached the same number of points, the second criteria comes into play and so on. Finally, if all criteria are the same, the teams share a place.</p><h2 id="input">Input</h2><ul><li><code>number</code>: Number of teams in your league.</li><li><code>games</code>: An array of arrays. Each item represents a played game with an array of four elements <code>[TeamA,TeamB,GoalA,GoalB]</code> (<code>TeamA</code> played against <code>TeamB</code> and scored <code>GoalA</code> goals and conceded <code>GoalB</code> goals ).</li></ul><h2 id="output">Output</h2><ul><li><code>positions</code>: An array of positions. The <code>i</code>-th item should be the position of the <code>i</code>-th team in your league.</li></ul><h1 id="example">Example</h1><pre><code>number = 6games = [[0, 5, 2, 2],   // Team 0 - Team 5 =&gt; 2:2         [1, 4, 0, 2],   // Team 1 - Team 4 =&gt; 0:2         [2, 3, 1, 2],   // Team 2 - Team 3 =&gt; 1:2         [1, 5, 2, 2],   // Team 1 - Team 5 =&gt; 2:2         [2, 0, 1, 1],   // Team 2 - Team 0 =&gt; 1:1         [3, 4, 1, 1],   // Team 3 - Team 4 =&gt; 1:1         [2, 5, 0, 2],   // Team 2 - Team 5 =&gt; 0:2         [3, 1, 1, 1],   // Team 3 - Team 1 =&gt; 1:1         [4, 0, 2, 0]]   // Team 4 - Team 0 =&gt; 2:0</code></pre><p>You may compute the following table:</p><table><thead><tr><th>Rank</th><th>Team</th><th>For : Against</th><th>GD</th><th>Points</th></tr></thead><tbody><tr><td>1.</td><td>Team 4</td><td>5 : 1</td><td>+4</td><td>5</td></tr><tr><td>2.</td><td>Team 5</td><td>6 : 4</td><td>+2</td><td>4</td></tr><tr><td>3.</td><td>Team 3</td><td>4 : 3</td><td>+1</td><td>4</td></tr><tr><td>4.</td><td>Team 0</td><td>3 : 5</td><td>-2</td><td>2</td></tr><tr><td>4.</td><td>Team 1</td><td>3 : 5</td><td>-2</td><td>2</td></tr><tr><td>6.</td><td>Team 2</td><td>2 : 5</td><td>-3</td><td>1</td></tr></tbody></table><p>Team 5 and Team 3 reached the same number of points. But since Team 5 got a better scoring differential, it ranks better than Team 3. All values of Team 0 and Team 1 are the same, so these teams share the fourth place.</p><p>In this example you have to return the array <code>[4, 4, 6, 3, 1, 2]</code>.</p>
