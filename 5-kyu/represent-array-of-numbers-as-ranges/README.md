<h2><a href=https://www.codewars.com/kata/58ab002d68ee07c57b000118/train/javascript target="_blank">Represent array of numbers as ranges</a></h2><h3>5 kyu</h3><h1 id="description">Description</h1><p>Your task is to take arrays of numbers and compress them into ranges.</p><p>The numbers in the array are mostly consecutive. If you convert them as ranges, it will save a lot of space. You should write a function that will convert an array of numbers into a string. A range, or series of consecutive numbers, will be represented as two numbers separated by an underscore, a range of one just by the number its self and multiple ranges separated by commas.</p><p>For example,<br>The numbers 5, 6, 7, 8 and 9 would be displayed as "5_9"<br>The number 6 would just be "6"<br>The numbers 3,4,5,6,9 would be "3_6,9"  </p><p>Using the above system, you should write two functions:<br>toRange - convert an array of numbers to a range string<br>toArray - convert a range string back to an array  </p><h2 id="warnings">Warnings</h2><p>The numbers could arrive all jumbled up so you'll need to sort themSometimes the same number may appear more than once, duplicates should be discarded.</p><h2 id="edge-cases">Edge cases</h2><p>An empty array should become an empty string if passed to <code>toRange</code> and vise versa for the <code>toArray</code> function. Also, ranges of 2 digits will take the same space whether they are represented as a sequence or a range. I.e. <code>"5,6,8,9".length === "5_6,8_9".length</code> so there will be no compression, but represent them as a range anyway for consistency.</p><p>Good luck!</p><p>If you're finding this Kata a little hard, then maybe try my other one first</p><p><a href="https://www.codewars.com/kata/find-the-first-non-consecutive-number" data-turbolinks="false" target="_blank">https://www.codewars.com/kata/find-the-first-non-consecutive-number</a></p>
