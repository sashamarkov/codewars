<h2><a href=https://www.codewars.com/kata/58a848258a6909dd35000003/train/python target="_blank">Mastermind</a></h2><h3>5 kyu</h3><h1 id="introduction">Introduction</h1><p>Mastermind or Master Mind is a code-breaking game for two players. The modern game with pegs was invented in 1970 by Mordecai Meirowitz, an Israeli postmaster and telecommunications expert. It resembles an earlier pencil and paper game called Bulls and Cows that may date back a century or more.(Source <a href="https://en.wikipedia.org/wiki/Mastermind_(board_game)" data-turbolinks="false" target="_blank">Wikipedia</a>)</p><p><img alt="mastermind board" src="https://raw.githubusercontent.com/adrianeyre/codewars/master/Ruby/Authored/mastermind.jpg"></p><h1 id="rules">Rules</h1><ol><li><p>The Mastermind (computer) will select 4 colours. The colours are randomly selected from <code>["Red", "Blue", "Green", "Orange", "Purple", "Yellow"]</code>. Colours can be duplicated but there will always be exactly <code>4</code>.</p></li><li><p>The Mastermind will return an array back to you. For every correctly positioned colour in the array an element of <code>"Black"</code> is returned. For every correct colour but in the wrong position an element of <code>"White"</code> will be returned.</p></li><li><p>Passing the correct array will pass the Kata test and return <code>"WON!"</code>.</p></li><li><p>Passing an invalid colour will fail the test with the error <code>"Error: you have given an invalid colour!"</code>.</p></li><li><p>Passing an invalid array length will fail the test with the error <code>"Error: you must pass 4 colours!"</code>.</p></li><li><p>Guessing more than 60 times will fail the test with the error <code>"Error: you have had more than 60 tries!"</code>.</p></li><li><p>All colours are capitalised.</p></li><li><p>The return array will be shuffled!</p></li></ol><h1 id="task">Task</h1><p>Your task is to create a method called <code>mastermind()</code> that will take an object called <code>game</code>. The object has already been preloaded so you do not need to worry about it.</p><p>Within your method you must pass an array into the game object method <code>.check()</code>. This will evoke the object to check your array to see if it is correct.</p><h1 id="example">Example</h1><p>If the Mastermind selected the following colours</p><p><img alt="secret code - red, blue,
